1. 투자 맥락

모든 금액은 원화 기준이에요. 미완성 입력도 임시 저장할 수 있어요.

2. 섹터와 위험 기준

선호는 분석 시 고려하고, 제외·비중 상한은 검증 조건으로 적용해요. 비율은 전체 제안 운용액 기준이에요.

보유 불러오기를 누르면 토스 섹터 목록을 가져와요. 여러 개 선택하려면 ⌘ 또는 Ctrl을 누르세요.

3. 현재 보유 확인

미국 주식 보유 수량을 조회해요. 매수가능금액을 실제 현금으로 간주하지 않아요.

아직 불러오지 않았어요.

4. 분석 실행

실행 설정을 확인하고 있어요.

Codex / API 실행 설정

Codex는 이 Mac의 로그인으로 실행해요. 투자 맥락·보유·시장 자료를 전달하며 Codex 사용 한도가 적용돼요.

시장 근거 → 독립 관점 3개 → 수치 평가·검증 → 리더 종합 → 최종 재검증을 실행해요. 자료 부족이나 조건 위반 시 보류할 수 있어요.
