# 전문 보고서를 비교 기준으로 쓰는 방법

조사일: 2026-11-17 · 공개 원문 중 투자 논증·포트폴리오 통제·성과 설명을 직접 확인할 수 있는 사례를 골랐어요. ‘세계 최고’를 객관적으로 순위화한 목록은 아니에요. 최고 수준을 지향하기 위한 **기능별 참조 묶음**이며, 기관의 명성이나 수익률 자체는 평가 기준이 아니에요.

아래 **원문 관찰**은 읽은 구간에 한정해요. **Mara 적용**은 그 관찰에서 정한 자체 평가 기준이에요. 원문의 투자 결론을 정답으로 가져오지 않으며 PDF 전문이나 도표를 재배포하지 않아요. 페이지는 PDF 1쪽부터 세어요.

B01–B04는 실제 자금 운용 보고의 비교 대상이고, B05는 기업분석의 논증 깊이, B06는 포트폴리오 구성 방법을 보완해요. 이 구분을 없애면 학생 종목 보고서가 개인 포트폴리오 전체의 답안으로 둔갑하거나 기관의 사후 성과가 최초 제안의 기준이 되는 문제가 생겨요.

## 3. 원문에서 가져올 것은 ‘수준’의 관찰물

| 비교 항목 | 원문과 나란히 확인할 Mara 산출물 | 부족하다고 판단하는 조건 | 개선 완료 증거 |
|---|---|---|---|
| 투자 논지 | 한 문장 주장, 핵심 사실, 반증, 가격과 연결 | 시황·기업 소개는 길지만 선택의 이유가 없음 | 주장별 원문과 반대 사실, 결론 변경 조건을 연결 |
| 기업의 질과 매수가 | 재무 기간, 사업 동인, 재투자·희석, 가치 범위, 현재 가격 | 가격 하락·성장률·명성만으로 매력적이라 판단 | 적합한 가치 방법과 가정·민감도·대체 방법의 차이 |
| 비중 결정 | 선택안과 작은/큰 비중, 단순 대안, 전체 위험 | 왜 그 비중인지 설명 없이 숫자만 제시 | 목표·위험·중복·비용의 변화를 같은 기준으로 비교 |
| 위험 설명 | 자본 비중, 경제적 노출, 충격·유동성·환율, 미확인 범위 | 종목 수를 분산으로 간주하거나 시나리오를 최대 손실로 표시 | 계산 가능한 노출·가정과 계산할 수 없는 범위를 분리 |
| 성과·비용 | 시점·통화·납입·비용 포함 범위·기준수익률 | 실제·가상 수익을 혼합하거나 비용을 중복 반영 | 같은 기준의 재현 가능한 표와 분모·각주 |
| 반론과 변경 | 불리한 결과·가정 실패·논지 변화 | 리더에게 유리한 근거만 남음 | 남은 이견과 수용/기각 이유, 다시 확인할 항목 |
| 읽기와 추적 | 요약→판단→도표→원문·계산 | 긴 문장과 표는 많지만 사용자가 핵심 선택을 설명하지 못함 | 독립 독자가 목표·선택·핵심 위험·변경 조건·근거 위치를 확인 |

이는 원문 기관의 공식 채점표가 아니라 Mara의 수용 기준이에요. 서식의 유사성이나 기관이 보유한 종목과의 일치로 점수를 주지 않아요. 결과가 공격적인지 보수적인지보다 목표와 근거에 맞는지를 판단해요.

## 4. 평가 기록에 반드시 남길 내용

각 비교 결과에는 `평가 범위·기준일·Mara 보고서 버전·평가기준 버전·비교 자료 ID/쪽·양쪽 근거 위치·판정·차이가 결정에 미치는 영향·수정 후 확인할 조건·리뷰어·한계`가 있어야 해요.

예를 들어 “가치평가가 약하다”로 끝내지 않아요. B05의 특정 표는 사업 가정에서 희석 주식수와 주당 가치까지 연결하지만, Mara의 해당 기업은 매출·CFO와 현재 가격만 있다면 **재투자·희석·평가 가정→가격의 연결이 없어서 비중을 정당화하지 못한다**고 적어요. 다만 ETF나 이미 탈락한 모든 후보에 같은 DCF를 강제하지 않아요.

비교 원문도 오류나 편향이 있을 수 있어요. 참조에 없는 반증이나 개인 유동성 항목이 Mara의 과제에 중요하면 여전히 요구해요. ‘참조보다 문장이 많다’와 ‘참조와 같은 수준의 논증을 갖췄다’를 구분해요.

## 5. 현재 Mara에 대해 말할 수 있는 범위

현재 Q1은 공개 보고서의 특징을 참고한 고정 기준과 원문 가이드로 평가해요. 이번 조사로 비교 표본과 관찰 항목을 구체화했지만, **같은 범위의 원문 구간을 익명 대조하고 평가자 편향까지 교정한 실험은 아직 수행하지 않았어요.** 따라서 이 문서만으로 현재 보고서가 위 자료와 동등하다고 판정하지 않아요.

별도 [평가 체계](evaluation-framework.md)에 따라 프로세스 대조 실험과 보고서 비교를 실행해야 해요. 비교 후에는 점수 하나보다 어느 기준에서 부족하고 그 부족함이 투자 결정에 어떤 영향을 주는지를 먼저 보여줘요.

## 6. 조사·보존 범위

이번에는 위 표에 적은 구간만 읽었어요. 보고서 전체, 전체 주가모형 또는 원문 기관의 내부 의사결정 과정을 감사한 것은 아니에요. 공개 PDF 원본과 텍스트는 로컬 캐시에 보관하고 URL·수집 시각·해시·읽은 범위만 작업 기록에 남겨요. 비공개 보고서·유료 자료·개인 계정 자료는 사용하지 않았어요.

Pershing PDF는 웹 도구의 크기 제한, CalPERS는 웹 도구의 접근 오류가 있어 같은 공식 공개 URL을 일반 HTTP 다운로드로 읽었어요. CalPERS 검색 결과의 짧은 지표 첨부본 대신 제목이 일치하는 21쪽 전체 Trust Level Review를 확인했어요. 문서가 다운로드됐다는 사실을 전부 읽었다는 뜻으로 기록하지 않아요.
