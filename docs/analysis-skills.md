# 분석 스킬과 제안 검증

버전 1.0 · 조사·적용일 2026-11-15. 사용자 요구와 실제 역할 응답의 공백에서 도출한 Mara의 실행 절차예요. 외부 기관이 Mara를 인증하거나 특정 배분을 권고했다는 뜻은 아니에요.

## 역할별 스킬

| 스킬 | 책임 역할 | 입력 → 결과 | 도구와 남은 공백 |
|---|---|---|---|
| 가계 재무와 유동성 | R1, Marks, R4, 리더 | 부동산·부채·지출 포함 여부 → 자기자본과 현금흐름, 필요한 개인 확인 | 일반 계산. 부동산 처분가·전체 부채·소득 지속성은 사용자 맥락/조건 |
| 신규 소득의 정기 적립 | R1, Bogle, R4, 리더 | 첫 예산·매월 납입·기간 의미 → 중복 없는 조건부 납입 계획 | 월/일수 주기 분리. 예정 입금은 실제 보유가 아님 |
| 개별 기업과 가격 검토 | Buffett, Marks, R4 | 연간 재무·공시·가격 → 사업 가설, 가격과 가치, 반증 | SEC 자료. 정상화 가치 모델·부채 만기·IR 본문은 아직 별도 조사 필요 |
| 분산 상품 검토 | Bogle, R4, 리더 | 목적·보수·구성·개인 제약 → 분산 대안과 집중/중복 | iShares. 모든 기업 내재가치가 지수 적립의 필수조건은 아님 |
| 기관 리포트와 언론 자료 | R2, Marks | 발표시점·출처·읽은 범위 → 사실/전망/보도/해석 구분 | BlackRock·Schwab·CNBC. 기사 본문·전체 표/분석을 읽었다고 하지 않음 |
| 자료 공백과 다음 행동 | 전 역할 | 누락·실패·제약 → 분류, 담당, 해소 기준 | 개인 확인/시장 수집/분석 역량/제약/주문 전/불확실성을 구분 |
| 제안과 보류 검증 | R4, 리더 | 실제 제안·수치·핵심 주장 → 검토 가능/보류 및 조건 | 원칙적 매수 강제나 전역 보류 없이 제안별 판단 |
| 자료와 판단 과정 회고 | R6, F1 | 당시 근거·실제 결과·현재 변화 → 결과/과정 평가, 지식 정리 | 납입과 수익 구분, 원본 보존, 단기 성과로 철학 자동 변경 금지 |

등록점은 `resources/analysis-skills.json`, 가이드는 `guides/skills/*.md`예요. 각 호출에 해당 스킬 본문을 주입하고 ID·버전·내용 해시와 전체 가이드를 `agent_input`에 저장해요. 대화는 해당 실행의 저장된 가이드를 사용하고, 아직 호출되지 않은 역할은 현재 가이드/스킬을 초기화해요. 새 스킬은 역량 절차이지 모델에 임의 쉘·주문·인터넷 권한을 부여하는 것이 아니에요.

## 판단별 경계

- **현재 투자 예산:** 주식 제안 기준액과 실제 계좌 평가액을 분리해요. 미래 소득이 재원이라면 아직 금융자산이 적어도 조건부 계획을 만들 수 있어요. 실제 입금으로 기록하지 않아요.
- **부동산:** 시가-담보대출은 부동산 자기자본이에요. 주식 매수 현금으로 더하지 않아요. 상환액이 지출에 포함돼 있으면 중복 차감하지 않아요. 미입력 잔액은 0으로 확정하지 않아요.
- **최소 시장 근거:** 새 제안에서 비중이 양수인 상품만 검사해요. 개별주는 기업 식별을 확인한 공시와 현재 매출/CFO 자료, 펀드는 목적·지수·보수·구성이 필요해요. 미지원 상품이나 실제 자료 공백은 그 상품의 제안을 보류해요. 이 검사는 가치평가·정성 적합성 완료가 아니에요.
- **수치 제약:** 손실 시나리오·상품/섹터/주식/외화 상한·필요 현금을 유지해요. 현금은 개별 상품 집중 상한에서 제외해요. 미확인 섹터 비중이 모두 하나의 섹터여도 상한 이하라면 상한 위반은 불가능하지만, 제외 섹터는 노출 확인 없이 통과시키지 않아요.
- **정성 검증:** 가격만으로 저평가를 주장하거나 중요한 비용·부채·현금 필요가 불명확하면 R4가 보류해요. 최소 근거 통과·기관 전망의 수·좋은 과거 수익만으로 승인하지 않아요.
- **주문 전 확인:** 최신 호가·거래 단위·계좌별 비용·실제 입금·주문 지시는 별도예요. 이런 항목이 미확인이라는 사실 자체가 모든 장기 배분 연구의 금지는 아니지만, 비용이나 체결 가능성이 전략의 핵심이면 해당 결론의 근거가 필요해요. 실제 주문 기능을 추가하거나 실행하지 않았어요.

`proposal.decision_status`는 `/api/contracts/decision`의 계약을 따라요. 정량 오류/자료 공백도 정성 findings와 병합되어 담당과 해소 조건을 보존해요. `monthly_allocation`은 목표 비중×정기 납입액으로 계산한 조건부 계획이고, 보류된 경우 화면에 참고 배분이라고 표시해요. 작업실 계약은 `mara.workbench/1.1.0`으로 확장하고 1.0 입력과 기존 원본을 계속 읽어요.

## 주간 입력 크기와 원본

한 직전 실행만 역할별로 재사용해요. 각 투자자에게 자기 관점의 원문과 리더의 이유·반론·위험·다음 점검을 전달하고, 검증·종합·회고에는 모든 이전 관점 원문을 유지해요. 중복된 수치 계산과 화면용 파생값은 제외하며 투영 이유와 원본 이벤트 ID를 입력에 남겨요. 원본 DB 기록은 수정하지 않아요.

시장 fact 본문 44,000자, 역할별 활성 지식 6,000자, 직전 시장 비교 8,000자 한도는 유지해요. 전체 입력은 일반 역할·추가 등록 역할 256,000자, 회고·기억 384,000자, 여러 현재/이전 관점을 함께 받는 검증·리더 512,000자로 제한해요. 이 한도에는 응답 교정 입력도 포함돼요. 모든 역할의 거의 24,000자 출력과 활성 지식, 전체 응답 교정이 이어지는 3주 합성 경계를 검증했어요. 이는 큰 입력의 실제 모델 품질이나 사용량 보장이 아니며, 제공자 한도에 걸리면 원본을 보존하고 명시적으로 실패해요.

## 공급자 선정과 접근 범위

인터넷 검색 후 실제 HTTP 응답을 확인했어요. [BlackRock](https://www.blackrock.com/corporate/insights/blackrock-investment-institute/global-weekly-commentary)과 [Schwab](https://www.schwab.com/learn/story/weekly-traders-outlook)의 공개 주간 논평을 연결했어요. 원문 HTML은 별도 보존하고 모델에는 발표일·제목·도입부 최대 150단어 발췌와 읽은 범위를 전달해요. 기관 의견이며 전체 보고서를 종합한 요약은 아니에요. 발행사의 기사 헤더 안에 제목과 하나의 날짜가 확인되는 경우만 채택하며, 별도 경제 달력이나 관련 기사 날짜를 발행일로 쓰지 않아요. 새 주에 원문 구조가 바뀌면 수집 실패로 남겨요.

[CNBC 공식 RSS](https://www.cnbc.com/id/100003114/device/rss/rss.html)는 최근 기사 탐색에 사용해요. 기사 본문을 읽거나 사건을 독립 확인했다고 표시하지 않아요. 미래 시각·오래된 제목·중복 URL·다른 호스트 링크를 제외해요.

[J.P. Morgan Weekly Market Recap](https://am.jpmorgan.com/us/en/asset-management/institutional/insights/market-insights/market-updates/weekly-market-recap/)도 조사했어요. 런타임 HTML은 본문 없는 동적 화면이고 PDF는 접근 가능했으나 날짜/표를 검증하는 PDF 파서를 이번 범위에서 연결하지 않았어요. 접근 성공을 분석 자료 수집 성공으로 표시하지 않아요. Reuters 등 유료/라이선스 경로는 구독이나 권한을 임의 취득하지 않았어요.

확장 우선순위는 개별주의 공시/IR 본문·만기와 가치평가 입력, 동일통화 배당 포함 총수익률, 사용자 제외 섹터와 ETF 분류 대조, 계좌별 비용이에요. 각 공백이 실제 제안을 막는지부터 판단하고, 모든 도구가 생길 때까지 전체 포트폴리오를 무조건 보류하지 않아요.
