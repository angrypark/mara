# Fact와 판단 연결

fact의 논리 ID와 당시 자료 버전을 분리해 관리해요. 보고서는 판단별로 어떤 fact를 사용했는지 기록하며, HTML에서 그 근거와 계산값을 바로 열 수 있어요.

## 저장 구조

원본 이벤트가 기준이에요. 다음 표는 원본을 바꾸지 않고 조회할 수 있도록 만든 색인이에요. 사용자와 완료 보고서의 범위를 함께 검사해요.

| 표·view | 역할 |
|---|---|
| `fact_catalog_versions` | 색인 schema 버전 |
| `fact_snapshots` | 논리 `fact_id`, 원본 전체와 부모 버전을 묶은 `snapshot_id`, schema와 본문 |
| `report_facts` | 완료 보고서가 가진 fact와 당시 snapshot 연결 |
| `report_claims` | 보고서 안의 `claim_id`, 판단 문장과 계산 경로 |
| `claim_facts` | 판단이 참고한 fact와 snapshot. 누락도 명시 |
| `fact_metadata` | 출처와 시점으로 자료를 찾는 SQL view |
| `judgment_evidence` | 판단에서 근거로, 근거에서 사용된 판단으로 찾는 SQL view |

기록은 추가만 할 수 있어요. 같은 논리 ID의 값·출처·시점·부모 자료 버전이 바뀌면 새 snapshot으로 저장해요. 과거 판단을 최신 자료로 다시 연결하지 않아요. 동일 원본을 다시 색인하면 같은 결과를 유지해요.

`mara.fact_catalog.authoritative_facts`는 해당 실행의 완료 시점까지 허용된 원본을 모아요. `persist`는 원본과 입력이 같은지 확인한 뒤 원자적으로 저장해요. `present`는 기존 색인도 다시 검사해요. 색인이 없거나 불일치하면 원본에서 표시를 구성하고 각각 `source_projection_not_indexed`, `index_mismatch_source_projection`으로 알려요. API 조회만으로 과거 보고서의 색인을 새로 저장하지 않아요.

## 계산의 근거

새 기업 가치 계산에는 원자료 해시와 해당 역할에 실제 전달한 표시본의 해시를 따로 남겨요. 계산이 사용한 부모 버전을 찾지 못하거나 다른 버전이면 일치했다고 표시하지 않아요. 예전 계산에 논리 ID만 남아 있다면 계산 당시의 원자료 버전은 미확인으로 표시해요.

자료 버전 연결은 추적을 위한 검사예요. 자료가 주장을 충분히 뒷받침하는지, 정상화 이익이나 재투자 가정이 타당한지는 별도 분석과 검증이 필요해요.

## Schema와 시계열

[fact snapshot](../contracts/fact-snapshot.schema.json), [fact graph](../contracts/fact-graph.schema.json), [price series](../contracts/price-series.schema.json) 계약으로 구조를 검사해요. 각 schema는 `GET /api/contracts/<name>`에서도 읽을 수 있어요.

가격 시계열에는 종목·통화·종가 종류·관측 주기·요청 기간·실제 관측값이 필요해요. HTML은 그래프와 원자료 표, 실제 시작·종료일, 계산 규칙을 함께 보여 줘요. 관측점을 잇는 선은 중간 가격을 관측했다는 뜻이 아니에요. 기간 수익률과 관측점마다의 하락 여부를 구분하며, 이것만으로 기간 내내 하락했다고 단정하지 않아요.

현재의 일부 시세 fact는 기간 변화율 같은 요약만 담고 있어요. 그런 자료에는 그래프를 만들지 않아요. 새 공급자의 최근 3개월 종가를 자동 수집하는 연결은 별도 구현이 필요해요.

## HTML에서 읽기

판단 문장과 근거 버튼의 hover·키보드 포커스·클릭으로 출처 패널을 열어요. 휴대폰에서는 탭으로 열고, 닫거나 Escape를 누르면 원래 문장으로 돌아와요. 원문 발췌와 전체 보존 JSON, 발표·인지·유효 시점, ID와 버전, 한계를 확인할 수 있어요. 외부 fact가 없는 계산 판단도 당시 계산값과 가정을 표시해요.

필수 자료가 없거나 시계열 형식이 잘못됐으면 그 상태를 표시해요. 빈 값에 그래프를 만들거나 자료가 없다는 이유로 판단 원문을 숨기지 않아요.
