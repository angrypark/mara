# 보류 이후 논증 준비

자료가 없거나 읽히지 않은 문제와, 자료가 있어도 정상화·가격·비중 논증이 부족한 문제를 구분해요. 보류 해제나 특정 자산 매수를 목표로 강제하지 않아요.

`thesis_workspace`는 동결된 후보 질문 ID에 기업 정상화·가격 조건·대안 비교, 상품 구성·집중·비용 검토를 연결해요. planner 매 회와 조사 후 실제 역할 입력에서 다시 만들며, 그 역할에 전달된 유효 fact만 안내해요. 반복 지침은 공유하고 탐색 위치는 제한해요. 전체 관측을 읽은 것으로 해석하지 않으며, 원문은 기존 xbrl_read/evidence_read로 확인해요. Bogle에게 투영되지 않은 상세 기업 재무를 다시 끼워 넣지 않아요.

`normalize_earnings`는 같은 연간 기간의 USD 관측 성분에 명시적 계수를 곱해 더하고 같은 기간의 shares로 나눠요. fact ID와 JSON 행 위치, 회사·기간·단위·알려진 시점을 대조하며 세 시나리오와 재투자·희석·반증 설명을 요구해요. 음수 결과는 그대로 남아요. 계수·빠진 비용·경제적으로 겹치는 서로 다른 항목·분할 기준은 별도 판단이 필요해요. CFO−capex를 자동 정답으로 정하지 않아요.

당기 PPE 취득 태그가 없다고 자본지출 전체가 없다고 단정하지 않아요. `productive_asset_purchases`는 소프트웨어·무형자산 등을 포함할 수 있는 별도 표준 태그예요. PPE-only `capital_expenditure`와 합치거나 기존 FCF proxy의 대체값으로 넣지 않아요. 검색 후 원문과 정확한 기간을 읽어요.

기존 `valuation`에 `normalization_fact_id`를 주면 관측 버전에서 정상화 산술을 재현하고 이익·주식 기준·출처를 대조해요. 원자료 → 정상화 → 가치 계산의 snapshot 부모를 저장해 근거 팝업에서 따라가요. 역할별 표시 메타데이터 추가는 관측 변경으로 취급하지 않지만 실제 수치·기간·출처가 바뀌면 다시 검증해야 해요. 기존 가치 계산도 가능하며 연결이 없으면 `not_bound`예요.

각 시나리오의 `price_implied_annual_earnings_per_share`는 성장률·할인율·기간·영구성장을 고정했을 때 관측 가격을 설명할 주당 이익이에요. `earnings_to_meet_margin_of_safety`는 명시한 안전마진을 충족할 이익이에요. 실제 적정가치나 매수 신호를 인증하지 않아요. 성장·할인율·안전마진의 기본값은 없어요.

리더가 구조화한 대안의 weights를 `analysis.alternative_comparisons`에서 기존 계산기로 재계산해요. 새 대안 i의 경로는 `/analysis/alternative_comparisons/i`예요. 리더는 계산 결과를 다시 읽고 최종 검증에 전달해요. 같은 자금·통화와 기존 위험 제약을 사용하고, 역사 수익률이 없는 조합에 지수 성과를 대입하지 않아요.

도구의 입력 계약은 `contracts/research-plan.schema.json`과 `contracts/earnings-bridge.schema.json`에 있어요. valuation.scenarios는 이름이 있는 객체 3개의 배열이에요. 객체 모양 오류는 실행 전에 거절하며 오류를 보류가 타당하다는 증거로 삼지 않아요.

이번 변경은 새 보고서를 자동 실행하지 않아요. 기존 개인 맥락·보유·보고서·질문 판정은 보존되며 다음 분석에서 새 환경이 적용돼요. 새 수치 연결이 계산 가능해져도 정상화 계수와 상품 편입·정확한 비중의 논증, B1 비교, 미래 투자 성과는 별도 검토 대상이에요.
