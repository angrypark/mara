# 투자 의사결정의 평가 체계

기준일: 2026-11-18 · 목적은 보기 좋은 답변의 점수화가 아니라 **개인의 목표에 맞는 포트폴리오를 근거 있게 구성하고, 부족한 부분을 효율적으로 해소하는지** 확인하는 것이에요.

**상태 구분:** R4·Q1·R6와 개발 리뷰는 현재 구현이에요. 아래 A1 애널리스트 프로세스 리뷰, 동일 조건 대조 실험, 외부 보고서의 익명 쌍대 비교는 이번에 정한 평가 설계예요. 자동 수집·채점이 모두 구현되거나 우수성이 입증됐다는 뜻은 아니에요. 기존 Q1 v2.0의 점수·과거 결과를 이 문서로 소급 변경하지 않아요.

**2026-11-18 추가:** 사용자 요청으로 B1 `단독 에이전트 대비 추가 가치`를 정식 평가 항목에 추가했어요. 실제 한 사례의 독립 비교와 재사용 가능한 집계기를 구현했어요. 기준 답변 생성과 독립 내용 평가는 별도로 수행하며, 매 분석마다 추가 모델 호출을 자동 실행하는 기능은 아니에요.

## 1. 평가 대상 여섯 가지

| 평가 | 묻는 질문 | 필요한 증거 | 서로 대체할 수 없는 이유 |
|---|---|---|---|
| 소프트웨어·제품 리뷰 | 저장·권한·계약·화면·실행이 올바른가? | 코드, 테스트, 실제 사용자 흐름 | 프로그램이 맞게 돌아가도 투자 논증은 빈약할 수 있어요. |
| A1 애널리스트 프로세스 리뷰 | 이 과정이 투자 가능한 선택지를 좁히고 결정의 질을 높이는가? | 실행 전 판단 과제, 조사·판단 이력, 대안, 공백 처리, 기준 프로세스와의 비교 | 에이전트 수나 보고서 길이로 유효성을 알 수 없어요. |
| R4 제안 검증 | 이 비중과 행동이 개인 조건·근거·계산에 맞는가? | 실제·계획 자금 구분, 제약, 수치와 정성 검증 | 한도 안에 있다는 사실이 가장 나은 선택이라는 뜻은 아니에요. |
| Q1 보고서 품질 | 독립 독자가 선택 이유와 한계를 검증할 수 있는가? | 원문, 계산, 반론, 외부 보고서의 해당 부분과 비교 | 정직한 보류 보고서도 목표한 분석을 완성하지 못했을 수 있어요. |
| B1 단독 에이전트 대비 추가 가치 | 복잡한 실행 구조가 단독 답변보다 무엇을 더 해결했는가? | 같은 과제의 기준 답변, 독립 내용 평가, 판단 차이, 조건 차이와 실행 비용 | 총점·가독성 상승만으로 투자 판단의 우위를 주장하지 않아요. |
| R6 실제 결과·과정 회고 | 실제로 무엇이 일어났고 어떤 판단이 기여했는가? | 확인된 보유·입출금·성과와 당시 예측·판단 | 좋은 과정에도 손실이 날 수 있고, 부실한 과정에도 일시적 이익이 날 수 있어요. |

이 구분은 투자 과정 실사와 운영 실사를 나누는 [CFA Institute의 Investment Manager Selection 공개 요약](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/investment-manager-selection)을 참고한 Mara의 설계예요. CFA가 Mara를 평가하거나 인증했다는 뜻은 아니에요.

## 2. 먼저 무엇을 결정할지 고정한다

평가 시작 전에 `의사결정 범위`를 작성해요. 대상 자금·통화·목표·기간·금지 사항·선택 가능한 자산·평가일·반드시 해결할 중요한 질문·비교 대안·완료 조건을 정해요. 조건부 연구와 실제 실행 준비도도 구분해요. 이후 범위 변경은 이유와 버전을 남겨요.

예를 들어 성장주와 섹터 ETF의 적립 계획이라면 “성장성이 좋은가”를 넘어 **어떤 사업 노출을 어떤 상품과 가격으로 살 것인지, 왜 그 비중인지, 전체 위험이 어떻게 달라지는지**가 과제예요. 기업을 선택하지 않았다는 이유로 처음 정한 핵심 비교를 사후 삭제해서는 안 돼요. 반대로 모든 후보에게 완전한 DCF를 요구하지도 않아요. 탈락 이유를 입증할 자료와 최종 후보에 필요한 깊이를 구분해요.

[개인별 목표와 제약에서 포트폴리오를 구성하는 CFA 공개 설명](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/basics-of-portfolio-planning-and-construction)을 출발점으로 삼되, 사용자에게 수익률 목표나 손실 허용치를 임의로 만들어 주지 않아요.

## 3. A1: 애널리스트 관점의 프로세스 수용 기준

A1은 실행 작성자와 분리된 리뷰 책임이에요. 현재 역할 목록에 새 자동 에이전트로 등록된 상태는 아니에요. 우선 고정된 과제와 실행 기록을 독립 리뷰어가 평가하고, 아래 관찰물이 안정적으로 쌓인 후 자동화를 연결해요.

| ID | 기준 | 통과에 필요한 관찰물 | 미충족의 예 |
|---|---|---|---|
| A01 | 목표가 실제 선택을 제약한다 | 목표·기간·납입·유동성·위험 조건이 후보 제외, 비중 또는 행동에 연결된 표 | 목표는 공격적인데 이유 없이 광범위 지수나 현금만 기본값으로 반복 |
| A02 | 후보 탐색과 탈락이 설명된다 | 조사한 범위와 선택 기준, 최종 후보, 중요한 탈락 이유, 조사하지 않은 영역 | 유명 종목 목록을 전수 조사나 최적 후보로 표현 |
| A03 | 조사 우선순위가 결정에 기여한다 | 중요한 질문별 필요한 자료·담당 역할·대체 경로·다음 확인 시점 | 같은 공백을 여러 역할이 반복 언급하고 아무도 해결하지 않음 |
| A04 | 기업·상품에서 가격까지 연결된다 | 사업 동인→매출·마진·재투자·희석→주당 가치 또는 적합한 대체 평가→현재 가격; ETF는 노출·구조·비용·대체 상품 | 좋은 기업이라는 설명만 있고 지금 가격으로 보유할 이유가 없음 |
| A05 | 종목 선택에서 배분으로 연결된다 | 각 포지션의 역할, 더 작거나 큰 비중의 대안, 집중·중복·위험 변화, 가정 민감도 | 근거 없이 정밀한 비중을 제시하거나 독립 의견을 단순 평균 |
| A06 | 반대 의견이 실질적으로 검토된다 | 결론을 바꿀 수 있는 반증을 찾아 검증하고 수용·기각·미해결 이유를 기록 | 반대 문장이 존재하지만 리더 선택에 어떤 영향도 설명하지 않음 |
| A07 | 결론과 중단 조건이 명확하다 | 유지·변경·보류의 비교 이유, 해소해야 할 공백, 담당·다음 행동·재평가 시점 | 끝없이 조사하거나 같은 이유로 보류하면서 다음 단계가 없음 |
| A08 | 다음 실행이 앞선 판단을 이용한다 | 유지된 전제·달라진 사실·달라진 비중을 연결하고 결과/과정 교훈을 구분 | 매주 초기 분석을 반복하거나 최근 수익만으로 철학을 교체 |

판정은 `충족 / 부분 충족 / 미충족 / 미검증`이에요. 모든 적용 필수 항목이 충족되고 중요한 결함이 없을 때만 프로세스 수용으로 표시해요. 범위상 제외하는 항목은 실행 전에 이유를 고정해요. 점수 평균으로 필수 결함을 상쇄하지 않아요. 보류를 선택해도 A04·A05의 미완성을 자동 면제하지 않으며, A07의 적절한 보류로 별도 인정해요.

## 4. 효율은 결정에 필요한 진전을 측정한다

비용 절감이 이번 우선 목표는 아니에요. 효율은 **같은 핵심 질문에 더 확실한 답을 주는 데 필요한 시간과 반복**으로 평가해요. 먼저 품질 기준을 만족하는지 보고, 그다음 같은 품질에서 효율을 비교해요.

| 지표 | 정의와 기록 방식 | 오해 방지 |
|---|---|---|
| 중요한 공백 해소율 | 시작 전에 고정한 중요한 질문 중 원문·전달·계산·재검증까지 확인한 수 / 적용 질문 수. 중요도별 수와 비율을 병기 | ‘공백을 설명함’과 ‘해결함’을 구분. 현금 선택으로 분모를 줄이지 않음 |
| 잘못된 통과 | 중요한 근거·제약 미충족인데 준비 완료로 내보낸 건수 / 전체 적용 사례 | 독립 기준 사례와 원문으로 판정. 보류 감소와 함께 보고하며 중요한 잘못된 통과는 수용을 막음 |
| 회피 가능한 보류 | 필요한 도구·자료가 접근 가능하지만 수집·전달·정규화·추론·계산 누락 때문에 결정하지 못한 건수 | 자료 자체의 부재, 사용자 조건 충돌, 투자 가설 불충분에 따른 타당한 보류와 분리 |
| 유효 조사 비율 | 중요한 질문을 해소하거나 반증을 추가하거나 불확실성 범위를 줄인 조사 / 전체 조사 | 결론이 그대로여도 확인 가치가 있을 수 있음. 도구 호출 수 자체는 보상하지 않음 |
| 불필요한 재작업 | 정보 변화 없는 중복 요청, 계약 오류 교정, 이미 답한 질문 반복 건수와 사유 | 독립적인 재검증·새 시점 갱신을 중복 낭비로 세지 않음 |
| 판단 도달 시간 | 기준 입력 준비부터 검토 가능한 결과까지의 경과 시간. 자료/모델 대기, 교정, 사용자 응답 대기를 분리 | 미완성 상태로 빨리 끝내서 좋은 점수를 얻지 못함 |
| 역할의 한계 기여 | 전체 팀과 해당 역할을 제거한 대조군의 필수 기준·결함·반증·시간 차이 | 발언량이나 채택 비중으로 역할 가치를 평가하지 않음 |

보류 사유는 `사용자 조건`, `시장 자료 접근`, `수집·정규화`, `분석·가치평가`, `검증·실행 장애`, `투자 가설 불충분`으로 구분해요. 분류 자체도 독립 리뷰와 기준 사례·원문으로 확인하고 무조건 외부 자료 부족으로 돌리지 않아요. 연구 종료 사유는 충분한 근거 확보, 추가 정보가 결정을 바꾸기 어려움, 접근 실패, 예산 소진으로 나눠 기록해요. 앞의 두 사유도 리뷰어가 근거를 확인해야 해요. 현재 이벤트에 일부 측정 재료가 있으나 위 지표를 완전하게 집계하는 기능은 아직 없어요. 특히 무엇을 ‘유효 조사’로 인정하는지는 원문과 판단 변화의 대조가 필요해요.

## 5. 시스템의 의사결정 방식과 포트폴리오를 따로 비교한다

**프로세스 대조군:** 같은 기준일·개인 맥락·후보·자료·허용 도구를 사용해 전체 팀, 동일 과제를 맡은 단일 애널리스트, 특정 역할을 제외한 팀을 비교해요. 별도 예산 조건은 명시하고 역할별 원문을 독립 평가해요. 표본 수·사례 유형과 모델/가이드 버전을 남기고 실패·보류·미완료를 포함한 전체 분모로 결과를 보고해요. 시간은 중앙값과 p90, 품질은 사례별 결과와 분포를 함께 제시해요. 미완료는 경과 시간을 별도 표시하며 완료 시간 통계에서 빠진 수를 밝혀요. 측정하지 못한 비용은 0 대신 미확인으로 남겨요. 현재 팀이 더 낫다는 결과는 아직 없어요.

**포트폴리오 대조군:** 현재 구성 유지, 납입금만으로 비중 조절, 실행 가능한 단순 저비용 배분, 목표에 더 적극적인 대안, 원화/달러 현금 대기를 비교해요. 단순 대안은 사용자의 투자 철학을 강제로 대체하는 추천이 아니라 복잡한 선택의 추가 가치를 설명하는 기준이에요. 허용되지 않은 대안은 실행 불가 진단용임을 표시해요.

비교의 통화, 기간, 납입/인출, 수수료·환전·세금 범위, 리밸런싱 규칙과 자료 기준일을 맞춰요. 주식 노출이 크게 다른 두 안의 수익 차이를 전부 종목 선정 능력으로 부르지 않아요. 기준 변경은 버전으로 남기고 과거 결과에 유리한 비교 대상을 사후 선택하지 않아요. [CPP 2025 보고서의 비교 기준 설명](https://www.cppinvestments.com/wp-content/uploads/attachments/CPP-Investments-F2025-Annual-Report-English.pdf#page=21)을 적용한 설계예요.

### B1: 단독 에이전트 대비 추가 가치

판단 품질·실행 구조 개선이나 제품 완성도를 평가할 때 반드시 함께 기록해요. 기준 답변이나 독립 평가가 없으면 **미측정**이에요. Q1에 임의의 가산점을 넣거나 과거 Q1 점수를 다시 계산하지 않아요.

| 지표 | 계산·기록 | 해석 |
|---|---|---|
| 내용 점수 차이 | 같은 기준의 Mara 총점 − 단독 답변 총점 | 시황·편집 개선도 포함하므로 판단 우위와 구분해요. |
| 배분 판단 차이 | C2 점수 차이와 실제 달라진 선택·이유 | 차이가 0이면 투자 판단이 좋아졌다고 설명하지 않아요. |
| 근거 품질 차이 | C3 점수 차이, 새로 확인한 반론·오류·공백 | 인용 수나 수집량 증가를 대신 쓰지 않아요. |
| 독립 쌍대 평가 | 어느 답변으로 조정을 결정할지, 각 답변만의 유효한 기여와 남은 결함 | 선호 이유를 실제 fact·claim·계산 또는 원문 구간에 연결해요. |
| 오류·미확인 상태 | 두 결과의 G1~G4를 pass/fail/unknown 그대로 기록 | unknown은 통과가 아니며 실패를 총점으로 상쇄하지 않아요. |
| 추가 실행 비용 | 호출·시간·토큰 및 실패·재개·편집·자료 수집 범위 | 품질 점수와 따로 보고해요. 범위가 다르면 속도 우위를 산출하지 않아요. |

공통 내용 기준은 [decision-content-rubric.json](../resources/decision-content-rubric.json)이에요. C1 시장 설명 25, C2 배분 판단 25, C3 근거 20, C4 개인 조건 15, C5 핵심 선정 15이며 각 0~4점, 근거가 있으면 0.5점 단위예요. 이 파일의 날짜·task는 최초 기준을 고정한 실험의 출처예요. 다음 사례의 기준일·페르소나·후보·자료·과제·모델·도구·이력·예산은 각 실행 기록에 따로 남겨요. 기준 자체를 바꾸면 새 버전으로 양쪽을 다시 평가해요.

동일 자료 단독 답변과 독립 웹 조사 답변은 별도 비교예요. 전자는 같은 자료를 해석하는 능력을, 후자는 자료를 찾는 단계까지 포함한 사용 경험을 봐요. 과거 판단·학습이나 모델 설정이 다르면 그 차이를 명시해요. 독립 리뷰어가 먼저 각 답변을 채점하고 이후 쌍대 평가해요. 익명화하지 못했다면 비블라인드로 기록하며, 여러 시도 중 가장 좋은 것만 남기지 않아요.

보류도 내용 평가 대상이에요. **근거를 비교한 끝에 현금을 선택한 경우**, **매수 논증을 완성하지 못해 임시 대기하는 경우**, **계산·입력·실행 제약으로 진행하지 못한 경우**를 구분하고 중복 원인도 남겨요. `보류의 적절성`과 `포트폴리오 구성 과제의 완성도`는 별개예요. 모든 자료가 존재한다고 가치평가가 완성되는 것도, 일부 근거가 부족하다고 항상 현금이 최선인 것도 아니에요.

독립 평가 JSON을 집계하는 명령은 다음과 같아요. DB와 보고서를 바꾸지 않고 모델도 호출하지 않아요.

```sh
python -m mara.baseline_comparison assessment.json --baseline single_agent --candidate mara
```

입력에는 원문 hash를 포함한 `outputs`, 고정 `rubric_sha256`, 비교 조건·한계인 `condition_limits`가 필요해요. 각 output의 `criteria`에는 id·score·weight·observation, `gates`에는 G1~G4의 상태가 있어야 해요. 집계기는 중복 항목·가중치·점수 범위·합계를 검증하고 C2/C3와 전체 차이를 따로 출력해요. 미평가 점수는 null과 가능한 범위로 남겨요. 원문 hash의 진실성이나 리뷰어의 독립성·사실 판정 자체를 인증하지는 않아요.

이번 사례의 집계는 내용 +8.125점, C2 0점, C3 0점이에요. 시황과 편집 개선은 확인했지만 더 좋은 배분 판단을 입증한 결과는 아니에요. 품질 gate에 unknown도 남아 있어 일반적인 우위나 투자 성과로 확대하지 않아요.

## 6. Q1: 보고서의 분석 품질과 전달 품질

현재 자동 Q1 v2.0은 아래 8개 축을 0~4단계로 평가해요. 총점만 보지 않고 단계별 관찰물, 필수 gate와 중요한 결함을 함께 검사해요.

| 축 | 비중 | 전문 보고서와 비교할 핵심 |
|---|---:|---|
| 목표·가계 적합성 | 15 | 투자 대상과 실제 자금, 납입 가능성·기간·위험의 연결 |
| 시장·기업 근거 | 15 | 중요한 주장에 맞는 원문·시점·단위·반대 근거 |
| 자산 선정·가격·가치 | 15 | 선택/탈락 이유, 기업의 질과 가격의 구분, ETF의 구조·내부 노출 |
| 배분과 대안 | 15 | 왜 이 비중인지, 유지·단순 대안·더 적극적인 안과 비교 |
| 위험과 검증 | 15 | 집중·중복·유동성·환율·스트레스, 계산의 정의와 한계 |
| 비용·실행 가능성 | 10 | 거래·보수·환전·세금 범위와 실제 실행 전 조건 |
| 반증·모니터링 | 10 | 판단 변경 조건, 관측 지표·시점, 유지·중단 규칙 |
| 추적성과 전달 | 5 | 결론→근거→계산 연결, 이해 가능한 요약·그림·한계 |

현재 엄격 통과는 **총점 85 이상, 모든 축 3 이상, 필수 gate 충족, 필수 근거 범위 지원, 중요한 결함 없음**을 함께 요구해요. 자료 무결성, 핵심 주장과 반증, 독립 계산, 개인 적합성과 권한, 필수 자료 공백을 점검해요. `미확인`도 통과가 아니에요. 이 수치는 Mara의 설계이며 전문기관의 공식 등급이나 ‘세계 최고 수준’ 인증선이 아니에요.

새 비교에서는 문장 길이나 표의 수보다 **핵심 결정을 이해하는 데 필요한 정보가 빠짐없이 연결되는가**를 봐요. 역할별 반 페이지 이상의 상세문은 최소 설명량이고 품질 점수의 가산 요인이 아니에요. 첫 요약은 결론·핵심 이유·위험·반대 의견·변경 조건을 빠르게 보여주고, 상세 근거와 계산으로 내려갈 수 있어야 해요.

## 7. 외부 보고서와의 대조 방법

[전문 보고서 비교 기준](report-comparison.md)의 원문을 기능별 표본으로 사용해요. 하나의 보고서를 정답 포트폴리오로 지정하거나 유명 기관의 문체를 복제하지 않아요.

1. 평가 전에 목적·범위·기준일과 비교할 원문 구간을 고정해요. 기업 가치평가, 전체 포트폴리오 위험, 비용/성과 설명 등 같은 기능끼리 비교해요.
2. Mara의 해당 구간과 참조 구간을 나란히 두고, 각 기준에 `Mara 근거 위치 / 참조 위치 / 동등·부족·우수·비교 불가 / 차이의 영향 / 수정 후 수용 조건`을 남겨요. 원문에 없는 전문성을 추정해 주지 않아요.
3. 명성·길이 효과를 줄이기 위해 가능한 범위에서 작성자와 점수를 가리고 순서를 바꿔 독립 판정해요. 출처·날짜·단위는 증거 판단에 필요하므로 숨기지 않아요. 완전한 익명화가 불가능하면 한계를 기록해요.
4. 다른 평가자나 설정의 재평가와 불일치를 남겨요. 같은 모델을 별도 호출한 Q1만으로 평가 편향이 제거됐다고 보지 않아요.
5. 명백한 단위 오류·무관한 인용·중요한 반론 누락을 넣은 검증 표본과 정상 표본으로 평가자를 교정해요. 겉보기는 좋지만 근거가 없는 보고서를 걸러내는지도 확인해요.
6. 기준 설계에 쓴 표본과 최종 확인용 표본을 분리해요. 같은 예시를 외워 점수를 높인 결과를 일반 품질로 확대하지 않아요.

사후 연차보고서는 당시 최초 제안에 없던 결과를 알고 있어요. 그러므로 성과·원인 설명의 구조만 비교하고 미래를 미리 알았어야 한다고 채점하지 않아요. 기관의 규모·레버리지·사모자산·투자기간·세금 조건도 개인 투자에 복사하지 않아요. 적합한 동일 기능 표본이 없으면 억지 점수 대신 비교 불가로 남겨요.

## 8. 백테스트와 실제 성과의 위치

정량 검증은 두 단계를 구분해요. **계산 재현**은 같은 자료와 규칙에서 숫자가 맞는지, **전략 검증**은 당시 이용 가능한 정보만으로 반복한 선택이 표본 밖에서도 유효한지 확인하는 일이에요. 독립 계산기와 같은 결과가 나왔다는 사실은 종목 선정 전략의 검증이 아니에요.

전략 검증을 하려면 당시의 후보군·공시 이용 가능 시점·상장폐지·기업행동·배당·환율·비용·납입을 재현하고, 학습/설계 기간과 평가 기간을 분리해요. 여러 설정 중 잘 나온 것만 고른 효과와 거래 시점 가정도 드러내요. 수익률뿐 아니라 손실·회복·회전율·비용·목표 달성과 유지 가능한 현금흐름을 함께 봐요. 없는 상관·일별 낙폭·성과를 대체 지수나 월말 자료로 꾸미지 않아요.

최초 제안은 아직 실제 결과가 없으므로 실제 성과를 미관측으로 남겨요. 이후 실제 보유·입출금으로 성과를 확인하고, 수익의 원인이 시장·환율·배분·선정·납입 중 무엇인지 자료가 허용하는 범위에서 분리해요. 단기 이익만으로 원칙이나 에이전트의 비중을 자동 변경하지 않아요.

## 9. 개선을 성공으로 인정하는 조건

개선 전의 과제·자료 시점·평가 기준을 고정하고, 중요한 결함별 수정 전후 근거를 연결해요. 기준 자체를 바꿨다면 같은 기준에서 재평가하기 전에는 점수 상승을 개선량으로 계산하지 않아요. 5회 개선 기능은 존재하지만, 다섯 번 실행했다는 사실과 품질 통과는 다르며 매주 자동 수행되는 필수 단계도 아니에요.

성공은 점수 상승 외에 **중요한 공백의 실제 해소, 필수 제약 유지, 근거 없는 주장 감소, 반론·대안의 강화, 독립 판정의 재현**으로 확인해요. 보류→매수의 변화 자체는 성공 지표가 아니에요. 좋은 근거로 유지하거나 보류하는 것도 타당한 결과지만, 목표한 포트폴리오 구성 과제가 미완료라면 그 상태를 유지해요.
