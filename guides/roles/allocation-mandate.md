# 현재 목표와 투자 부분 · v1.0 · 2026-11-17

이 규칙은 과거 사례의 종목/비중보다 현재 profile을 우선하는 공통 입력 해석 규칙이다. 가이드의 과거 보고서 사례는 사용자 과거 판단이나 이번 추천 출발점이 아니다. history_scope.reset_id가 있으면 그 이전 제안·회고·점수·학습된 기억을 추측하거나 복원하지 않는다. 현재 사실과 기본 투자 철학은 유지한다.

profile.investment_style=aggressive_innovation이면 목표는 혁신·성장 기업과 섹터 ETF를 통한 공격적 투자 부분이다. 광범위 지수는 비교 기준이며 기본 추천 비중이 아니다. 시장 자료를 확인하여 개별 기업과 섹터 ETF의 대안·가격·실패 조건을 분석한다. 이름/인원수/높은 위험 자체는 수익의 근거가 아니다. 개별주나 섹터 ETF가 부적합하면 근거와 미충족 조건을 명시하되 사용자가 원한 구성과 다른 광범위 지수안을 같은 목표를 달성한 것처럼 설명하지 않는다. 저렴한 지수라는 이유만으로 모든 혁신 기업의 분석을 생략하지 않는다.

profile.usd_buffer_reference_fraction은 월 적립금 중 달러 현금 완충의 **비교 기준**이다. 확정 주문/강제 최소비중이 아니다. 달러 현금 USD_CASH와 원화 CASH를 구별하고, 다른 분할을 제안하면 이유를 밝힌다. 전체 납입비중의 합은 1이다. 투자 부분 내부 비중은 현금성 자산을 제외한 비중으로 다시 나눈다. 예: 주식 A 0.4, 주식 B 0.2, USD_CASH 0.4이면 투자 내부는 A 2/3, B 1/3이다. 실제 보유·가계 전체 현금·부동산을 이 분모에 더하지 않는다. 투자 부분이 0이면 내부 배분은 미정이다.

현금 완충은 투자 부분의 손실을 없애지 않는다. USD_CASH는 원화 지출 대비 환율 위험이 있으며 원화 비상금과 동일하지 않다. 기존 숫자 제약은 전체 proposal_capital 기준 그대로다. 위험 선호는 손실 감내능력 확인과 다르며 과거 손실 기준과 분석 전용 예산을 구별한다. 24개월 같은 재평가 시점을 강제 매도일이나 확정 5년 보유로 바꾸지 않는다. 미래 납입 가능성·소득 중단·복합 충격을 검증한다.

상세 보고서는 현재 실제 보유와 이번 납입 계획, 현재 시황, 전문가의 판단 절차, 개별 후보의 가격/가정/반증 조건, 최종 의견과 반론을 연결한다. 기술 성장→회사 매출→현금흐름/희석→현재 가격에서의 수익 기회를 구분한다. 공격적 희망 때문에 검증 기준·보고서 평가를 낮추지 않는다. 사실이 부족하면 가정으로 명명하고 조건부 연구 제안을 제시하며 없는 사실을 창작하지 않는다.
