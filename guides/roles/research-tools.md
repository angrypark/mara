# 시장 자료 도구 가이드
버전 1.0 · 2026-11-15

R2 수집 단계는 일반 코드 `Research.enrich`가 담당해요. 개인 맥락·계좌 정보는 외부 공시/거시/상품 공급자에 보내지 않고, 공개 심볼/CIK/지표 ID만 조회해요. `mara.research/1.0.0` 계약의 도구별 status와 fact_ids로 실제 성공 범위를 확인해요. 모델은 임의 인터넷·쉘·주문 도구 권한을 받지 않아요.

- 시황: Treasury 금리는 연율 par 수익률이며 자산 수익률이 아니에요. BLS 관측 월·이번 수집 시점·수정 가능성을 구분해요. Fed RSS는 정책 발표 요약이며 산업/지정학/기업 뉴스 전체가 아니에요.
- Buffett: SEC 연간 매출·이익·영업현금·설비투자와 최근 재무상태를 기간·단위별로 검토해요. 연간 수치에 3분기 누적을 더해 TTM으로 만들지 않아요. CFO−capex를 유지투자 차감 후 주주이익으로 부르지 않아요. EPS와 현재가격은 주식분할/주식종류/회계기간 대조 전 단순 PE로 확정하지 않아요.
- Marks: 부채 태그의 current/noncurrent/total을 중복 합산하지 않아요. 만기표·약정·차환 능력은 표준 수치만으로 검증했다고 하지 않아요. 거시 지표와 기업 자료를 다른 출처로 대조하되 하나의 전망으로 강제하지 않아요.
- Bogle: ITOT·IVV는 운용사 자료를 연결한 비교 사례이며 추천 기본값이 아니에요. 사용자 후보 밖이면 편입 비중에 넣지 말고 비교 대안으로 설명해요. 보수율은 총 거래비용이 아니에요. 전량 CSV 보존과 상위 보유 요약을 구분하고, 운용사 섹터를 토스의 사용자 제외 섹터와 동일시하지 않아요.
- 검증/리더: 자료가 추가되었으면 막연히 전부 '없음'이라고 반복하지 말고 실제 새 수치/공시/지표가 무엇을 판단 가능하게 했는지 인용해요. 수집하지 않은 부분과 추가 정성 검토가 필요한 부분을 구분해요. 부분 수집 성공으로 `actionable_risky_allocation=false`나 개인 제약을 무시하지 않아요.
- 일봉/호가: 수정주가 변화와 거래량은 배당 재투자/환율/비용 반영 총수익률이 아니에요. 호가의 관측 시각과 현재 체결 가능성을 구분해요. 위험 지표 입력에 대체하거나 유동성이 보장된다고 표현하지 않아요.

원문은 응답 바이트의 SHA-256 및 수집 시각으로 보존해요. cache_hit는 최초 수집 시점을 유지해요. 역할 입력에는 필요한 수치와 한계가 담긴 요약만 들어가며, 전체 수치·접수번호·원본은 실행의 시장 스냅샷과 원문 링크에서 확인해요. 기업 최대 8개·자료/시간 한도를 넘어 제외된 후보를 조사한 것처럼 쓰지 않아요. 이전 스냅샷과 현재 수정치를 구분하고 과거를 새 자료로 다시 쓰지 않아요.

변경 이유: 2026-11-15 실제 역할 피드백의 재무·거시·ETF·거래량 공백에 대응해 검증 가능한 수집 결과를 분석 입력에 연결했어요. 철학이나 관점 가중치를 바꾸지 않아요.
