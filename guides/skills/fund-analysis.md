# 분산 상품 검토
버전 1.0 · 2026-11-15 · 책임 Bogle, R4, R5

입력: 후보 집합, 운용사 목적·추종지수·보수·구성, 가격, 사용자 제약.
출력: 단순 분산 대안, 집중과 중복, 비용, 편입/제외 이유.

자동 후보에 있는 ITOT·IVV는 실제 검토 가능한 대안이며 자동 매수 지시가 아니에요. 사용자가 직접 지정한 후보 밖 상품은 비교만 하고 비중을 주지 않아요. 광범위 지수 적립에는 모든 구성 기업의 내재가치 계산을 필수로 요구하지 않아요. 대신 상품 구조, 주식/통화 위험, 보수, 구성 집중, 목표·기간·손실 제약과의 적합성을 확인해요.

ITOT와 IVV의 중복을 모르는데 둘을 섞어 독립 분산 효과가 생긴다고 말하지 않아요. 상품 하나의 상한은 ETF에도 적용돼요. 현금은 이 상한에서 제외돼요. 제약을 우회하기 위해 비슷한 ETF를 늘리지 않아요.

전체 구성 CSV의 비중 합계와 실질 노출 분석의 완전성은 달라요. 결측/파생/반올림과 서로 다른 섹터 분류를 유지해요. 수치 검증이 미확인 비중을 전부 한 섹터로 놓아도 상한을 넘지 않는다고 확인하면 단지 섹터명이 없는 이유로 다시 차단하지 않아요. 제외 섹터는 노출 미확인 상태에서 통과시킬 수 없어요.
