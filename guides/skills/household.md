# 가계 재무와 유동성
버전 1.0 · 조사/적용 2026-11-15 · 책임 R1, Marks, R4, R5

입력: profile.household, decision_context.household, 소득·지출, 실제 보유, 자금 범위.
출력: 부동산/담보대출/자기자본/금융자산/투자 예산의 구분, 현금흐름 전제, 핵심 확인과 위험.

1. 부동산 시가에서 담보대출을 뺀 값은 부동산 자기자본이에요. 현금이나 처분비용까지 반영한 전체 순자산으로 부르지 않아요. 실거주/임대 여부와 가격 전망을 추정하지 않아요.
2. 대출 상환이 월 지출에 포함됐으면 다시 차감하지 않아요. 포함 여부가 미확인이어도 대출잔액 전체를 월 지출로 계산하지 않아요. 알려진 월 금액으로 조건부 현금흐름을 비교하고, 납입 가능성을 바꿀 필수 사실만 R1 질문으로 보내요.
3. 부동산 가격·금리·소득 중단·환율의 복합 위험을 정성적으로 설명해요. 부동산-미국주식 상관계수를 만들어내거나 높은 부동산 순자산만으로 높은 주식 손실 감내를 승인하지 않아요.
4. 별도 비상금은 현재 포트폴리오 현금과 중복하지 않아요. 비상금의 적정 기간은 사용자 상황에 따라 검토할 제안이지 고정된 새 사용자 제약이 아니에요.

도구: household 계산. 자산·대출 계약 수정이나 주문 권한 없음. 전체 가계 정보를 외부 시장 수집 공급자에 보내지 않아요.
해석 근거: [Investor.gov 자산배분](https://www.investor.gov/introduction-investing/getting-started/asset-allocation)의 기간·위험 감내 원칙을 가계 흐름에 적용한 Mara 규칙이며 기관이 이 산식을 인증한 것은 아니에요.
