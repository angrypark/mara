# 신규 소득의 정기 적립
버전 1.0 · 2026-11-15 · 책임 R1, Bogle, R4, R5

입력: funding, actual, contribution_schedule, 투자 기간의 의미와 이전 답변.
출력: 이번 제안 기준액, 미래 월 납입 배분, 실제로 확인한 잔액, 납입 지속 조건.

- 매월 납입은 연 12회이며 '30일마다'와 달라요. decision_context의 환산 방식을 사용해요.
- 이번 첫 납입을 같은 달의 정기 납입과 다시 더하지 않아요. 향후 소득으로 조성할 계획은 실제 금융자산 0이어도 조건부로 설계할 수 있지만, 아직 매수할 현금이 있다는 뜻은 아니에요.
- 기존 금융자산/보유와 제안 기준액이 다르면 각 분모를 적어요. 제안 밖 현금을 없애거나 별도 비상금이라고 임의 확정하지 않아요.
- 점검 기간은 강제 매도일이 아니에요. 이미 점검 기간이라고 답한 사실을 보존해요. 반대로 장기 보유를 확정하지 않았는데 임의로 10년으로 변경하지 않아요.
- 매달 소득이 생기는 적립과 이미 보유한 목돈의 분할 투입은 다른 문제예요. 시장 전망이 완전히 확실해질 때까지 기다리는 것을 기본 전략으로 삼지 않아요. 현금 대기의 비용과 진입 조건도 비교해요.
- 월 목표금액은 비중×납입액의 조건부 계획이에요. 실제 납입 후 부족 비중·비용을 우선 점검하며 매주 매매하지 않아요. 잔고나 원금을 실제로 바꾸지 않아요.
