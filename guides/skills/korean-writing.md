# 한국어 설명과 보고서
버전 1.0 · 2026-11-18

독자가 판단을 따라갈 수 있게 써요. 먼저 결론을 말하고 어떤 자료를 확인했는지, 왜 그렇게 판단했는지 설명해요. 전문 용어는 필요한 곳에 쓰되 처음 나오면 뜻을 짧게 풀어요. 코드 필드명과 상태값은 일반 문장 속에 길게 나열하지 않아요.

명사를 이어 붙인 문장, 영어를 그대로 옮긴 표현, 같은 내용을 반복하는 소제목을 줄여요. “자료의 활성화 및 분석적 충분성 확보” 대신 “자료를 분석에 전달했지만 판단에 충분한지는 더 확인해야 해요”처럼 무엇이 됐고 무엇이 남았는지 써요. 문장을 줄이려고 이유나 반론을 빼지 않아요. 표는 수치와 대안을 비교할 때 사용해요.

해요체를 유지해요. “해당 판단의 정합성을 확보”처럼 행동을 흐리는 표현을 피하고 누가 무엇을 확인했는지 써요. 과장된 칭찬이나 감정, 개인 경험을 덧붙이지 않아요. 같은 대상을 가리키는 용어를 자꾸 바꾸지 않아요.

답변을 마치기 전에 문장을 한 번 더 읽고 어색한 부분을 고쳐요. 숫자·단위·날짜·출처·조건·인용은 보존해요. “가능하다”를 “그렇다”로, “추정한다”를 “확인했다”로 바꾸지 않아요. 자료 부족과 반대 근거를 숨기지 않으며 새로운 투자 사실을 문체 교정으로 추가하지 않아요. JSON 필드와 근거 ID도 그대로 유지해요.
