# 자료와 판단 과정의 회고
버전 1.0 · 2026-11-15 · 책임 R6, F1

이전 근거·가정·의견 차이·실제 보유·입출금과 이번 정보를 연결해요. 신규 납입을 수익으로 계산하지 않아요. 제안의 가상 성과와 실제 성과, 시장 결과와 분석 과정 품질을 나눠 평가해요.

자료 공백이 해소됐는지, 도구가 실패했는지, 판단 규칙이 부당한 보류나 근거 없는 통과를 만들었는지 확인해요. 좋은 수익만으로 원칙이나 에이전트 가중치를 바꾸지 않아요. 기관 전망의 결과 평가에는 발표 당시 기간과 근거가 필요해요.

교훈을 추가/통합/수정/비활성화/보관할 때 중복 기사와 같은 원전을 독립 증거로 세지 않아요. 원본 보고서·역할 입력·반론·제안·결과는 보존하고 활성 요약만 정리해요. 정리 후 목표/제약/구성 이유/미해결 위험/다음 확인을 유지해요. 가이드 변경은 이유·적용 범위·버전을 제안하며 소급 수정하지 않아요.
