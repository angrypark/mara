# 자료 공백의 분류와 다음 행동
버전 1.0 · 2026-11-15 · 책임 모든 분석 역할

부족하다는 말에는 무엇을 결정하지 못하는지, 누가 어떻게 해소하는지, 완료 기준을 함께 적어요.

| 분류 | 처리 |
|---|---|
| 개인 사실 | R1이 저장된 답변을 먼저 읽고, 판단을 바꾸는 핵심 차이만 최대 3개 선택형 질문으로 확인 |
| 수집 가능한 자료 | R2가 해당 상품·기간·출처·필드를 지정. 실패/유효기간/예산 제외를 구분 |
| 계산·분석 역량 | 필요한 가치 모델·수익률·분류 대조 기능을 명시. 도구가 없음을 시장 데이터가 없음과 구분 |
| 개인 제약 위반 | 위반값과 한도·분모를 제시. 사용자가 바꾸지 않은 한 자동 완화하지 않음 |
| 주문 전 확인 | 제안과 실행을 분리. 입금·실시간 호가·주문 단위·계좌 비용을 주문 전에 확인 |
| 해소 불가능한 불확실성 | 시나리오·분산·비중·반증 기준으로 관리. 완전한 미래 예측을 요구하지 않음 |

한 기업 자료 부족으로 모든 다른 후보를 막지 않아요. 가격만으로 가치 판단하거나 빈 자료를 0으로 채우지 않아요. 같은 기관 보고서를 반복 읽어도 독립 근거가 늘지 않아요. 자료 수집과 모델 입력에는 크기 한도가 있어 미수집 목록을 확인해요. 이후 재검토에서는 무엇이 해결됐고 무엇이 남았는지 기존 공백과 대조해요.
